# CodeAlpha — Image Gallery (Task 1)

A responsive image gallery built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive grid layout for desktop, tablet, and mobile.
- Category filters: All, Nature, Architecture, and Lifestyle.
- Lightbox image viewer with previous/next navigation.
- Keyboard controls: Escape to close, Left/Right arrows to navigate.
- Hover effects, smooth transitions, accessible labels, and image alt text.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Internet access is required to load the Google Fonts and remote Unsplash photos.

## Customize
Replace the image URLs in `index.html` with your own photos. Keep each card's `data-category` and `data-index` attributes, and update the visible count if you add or remove cards.

## GitHub
Create a repository named `CodeAlpha_ImageGallery`, then upload `index.html`, `style.css`, `script.js`, and `README.md`.
